# Aniekan Portfolio Website

This project is a multi-page Next.js (App Router) portfolio site generated from:

- `portfolio_instructions.json`
- `aniekan.resume.pdf`

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Shadcn-style component structure (`components/ui/*`)

## Pages

- `/` Home summary and highlighted outcomes
- `/experience` Detailed experience timeline and responsibilities
- `/projects` Case-study style project catalog
- `/about` Skills, education, certifications, and service

## Content source

Portfolio content is centralized in `lib/portfolio-data.ts`.

## Project documentation

Use `docs/project-case-study-template.md` to keep every project documented in a consistent, employer-focused technical case study format.
